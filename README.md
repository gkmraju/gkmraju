## How I work

- Separate data collection, decision logic, execution, and reporting.
- Make assumptions and current product boundaries explicit.
- Prefer deterministic tests for financial and safety-sensitive calculations.
- Treat forks as forks: sync, assess, or archive unless divergence is purposeful.
- Keep project claims tied to code, documentation, or validation that can be checked.
